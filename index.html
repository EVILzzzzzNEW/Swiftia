About the exploit

SwiftSword is a kernel exploit supporting iOS 26.6 through 27.0.1. It leverages a race condition in the physical page mapping subsystem to gain kernel read & write, then patches the platform trust cache and remounts the rootfs.

  • Kernel read/write via physmap race
  • Trust cache injection, no kernel patches
  • RootFS remount, stable across reboots

About the jailbreak

Swiftia is a semi-untethered jailbreak. It installs a lightweight bootstrap with Sileo for packages, tweaks and themes. After the initial run your device stays jailbroken until you reboot and re-jailbreak.

  • Sileo built in with themes & tweaks
  • Remove Jailbreak from the main page any time

Not sure about your iOS?

Open Settings → General → About → Software Version and check that it is between 26.6 and 27.0.1 before installing.
